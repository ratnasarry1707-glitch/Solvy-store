Unzip the download and keep the folder togetherEkstrak zip dan jangan pisahkan isi foldernya

After checkout you get a .zip file. Right-click it and choose Extract All (Windows) or double-click it (Mac). You will get one folder that looks like this:

Setelah bayar kamu dapat file .zip. Klik kanan lalu pilih Extract All (Windows) atau klik dua kali (Mac). Hasilnya satu folder seperti ini:

02PreviewLihat hasil1 min

Open it on your computerBuka di komputer kamu

  1. Double-click index.html. It opens in Chrome, Safari or Edge, exactly like the live demo.
  2. Right-click index.html and choose Open with → Visual Studio Code. This is where you edit.
  3. Keep both windows side by side. After every change press Ctrl + S (Mac: ⌘ + S) in VS Code, then refresh the browser with F5 (Mac: ⌘ + R).
  1. Klik dua kali index.html. Website terbuka di Chrome, Safari atau Edge, sama persis seperti live demo.
  2. Klik kanan index.html, pilih Open with → Visual Studio Code. Di sinilah kamu mengedit.
  3. Taruh dua jendela berdampingan. Setiap selesai mengubah, tekan Ctrl + S (Mac: ⌘ + S) di VS Code, lalu refresh browser dengan F5 (Mac: ⌘ + R).
03TextTeks5 min

Change the wordsGanti teksnya

In VS Code press Ctrl + F and type a few words you see on the page, for example Skin that looks like you. VS Code jumps to that line. Change only the words between the > and <.

Di VS Code tekan Ctrl + F lalu ketik beberapa kata yang kamu lihat di halaman, misalnya Skin that looks like you. VS Code langsung lompat ke baris itu. Ganti hanya kata-kata di antara tanda > dan <.

index.html
<h1>Lune</h1>
<p class="sub">Skin that looks like you, only rested.</p>
<p class="sub">Kulit sehat, hasil natural.</p>
<a class="btn" href="#book">Book a free consultation</a>
  • Don't delete the tags in pink (<p>, </p>). They hold the design.
  • Made a mistake? Press Ctrl + Z to undo, as many times as you need.
  • To change a whole word everywhere at once (like a brand name), use Ctrl + H (Replace).
  • Jangan hapus tag yang berwarna pink (<p>, </p>). Itu yang menjaga desainnya.
  • Salah edit? Tekan Ctrl + Z untuk membatalkan, berapa kali pun.
  • Untuk mengganti satu kata di semua tempat sekaligus (misalnya nama brand), pakai Ctrl + H (Replace).

05PhotosFoto5 min

Swap the photosGanti foto

The easiest way: put your photo in the img folder with exactly the same file name as the one you replace (for example hero.jpg), and delete the old one. Nothing in the code needs to change.

Cara paling gampang: taruh fotomu di folder img dengan nama file yang persis sama dengan foto yang mau diganti (misalnya hero.jpg), lalu hapus yang lama. Kode tidak perlu diubah sama sekali.

Photos are cropped to fit, so the centre of your photo is what people see. Keep faces and products in the middle. To change the short description that screen readers and Google read, edit the alt="…" text next to the image.

Foto otomatis dipotong agar pas, jadi bagian tengah foto yang terlihat. Taruh wajah dan produk di tengah. Untuk mengganti deskripsi foto yang dibaca Google, edit teks alt="…" di sebelah gambar.

09Domain10 min + waiting

Use your own domainPakai domain sendiri

  1. Buy a domain at any registrar (Niagahoster, Rumahweb, Namecheap, Cloudflare). A .com or .id costs around Rp150–250k a year.
  2. In Netlify open Domain management → Add a domain and type your domain.
  3. In your registrar's DNS page, add the two records below. Netlify shows the exact values for your site.
  4. Wait. It usually works within an hour, sometimes up to 24 hours. Netlify adds the free HTTPS padlock automatically.
  1. Beli domain di registrar mana pun (Niagahoster, Rumahweb, Namecheap, Cloudflare). Domain .com atau .id sekitar Rp150–250 ribu per tahun.
  2. Di Netlify buka Domain management → Add a domain lalu ketik domain kamu.
  3. Di halaman DNS registrar, tambahkan dua record di bawah. Netlify menampilkan nilai yang tepat untuk situsmu.
  4. Tunggu. Biasanya aktif dalam satu jam, kadang sampai 24 jam. Netlify otomatis memasang gembok HTTPS gratis.

Something not working?Ada yang tidak jalan?

Photos are missing or the letters look differentFoto hilang atau hurufnya berubah

index.html was moved away from its img and fonts folders. Put them back in the same folder, or upload the whole folder again.

index.html terpisah dari folder img dan fonts. Satukan lagi dalam satu folder, atau upload ulang folder utuhnya.

One photo doesn't showSatu foto tidak muncul

The file name doesn't match exactly. Check uppercase letters and the ending: hero.jpg, hero.JPG and hero.jpeg are three different names online.

Nama file tidak persis sama. Cek huruf besar kecil dan akhirannya: hero.jpg, hero.JPG dan hero.jpeg dianggap tiga nama berbeda saat online.

The layout broke after I editedTampilan berantakan setelah diedit

A tag or quote mark was deleted by accident. Press Ctrl + Z in VS Code until the page looks right again, then edit only the words between the tags.

Ada tag atau tanda kutip yang tidak sengaja terhapus. Tekan Ctrl + Z di VS Code sampai tampilan normal lagi, lalu edit hanya kata-kata di antara tag.

WhatsApp opens the wrong numberWhatsApp membuka nomor yang salah

The number must start with the country code and have no +, spaces or dashes, for example 6281234567890. Use the fixer in step 06.

Nomor harus diawali kode negara tanpa +, spasi atau strip, contohnya 6281234567890. Pakai perapih nomor di langkah 06.

My changes don't show on the live sitePerubahan tidak muncul di website online

Drag the updated folder into Netlify again (Deploys tab), then refresh your phone with the browser's reload button. Old versions can stay cached for a minute.

Drag lagi folder terbaru ke Netlify (tab Deploys), lalu refresh browser di HP. Versi lama kadang masih tersimpan sekitar satu menit.
